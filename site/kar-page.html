02 INSTALL

IPHONE · IPAD — SAFARI
  1. Open karpage.app in Safari.
  2. Tap ⋯, then Share (or just Share, depending on your tab layout).
  3. Scroll down and tap Add to Home Screen. Keep Open as Web App on.
  4. Tap Add.
ANDROID — CHROME
  1. Open karpage.app in Chrome.
  2. Tap ⋮ (More) beside the address bar.
  3. Tap Install app (Install and create shortcut, or Add to home screen, on some versions).
  4. Tap Install.
DESKTOP — CHROME · EDGE
  1. Open karpage.app.
  2. Click the Install icon in the address bar (Chrome also has ⋮ › Cast, save, and share › Install page as app).
  3. Confirm Install.
  4. On Omarchy, use Kar Page Launcher below.

Kar Page is a web app (PWA): once added, it opens from its own icon, full screen, like an app.
