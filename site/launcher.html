Kar Page Launcher

PUBLIC

Kar Page as a desktop app on Omarchy

It adds a launcher entry and an icon, and opens karpage.app in its own Chromium app window. The install script is short and readable, and the command opens it in less before it runs.

INSTALL

01 FEATURES

ONE ENTRY

Copies a launcher entry and an icon into your home folder. That is the whole install.

OWN WINDOW

Opens karpage.app in its own Chromium app window, sized like a phone.

NO SUDO

No sudo, no network and no packages. If Chromium is missing it stops and says how to get it.

READ IT FIRST

less shows the install script before it runs. Press q to install, or Ctrl-C to stop.

02 INSTALL

INSTALL
git clone https://github.com/KarPage/karpage-omarchy.git && cd karpage-omarchy && less install && ./install
installs 2 files · 171 KB · 5.7 MB clone
LAUNCH BY HAND
chromium --app=https://karpage.app --class=KarPage --window-size=480,960

The window uses the same Chromium profile as the browser, so a Kar Page sign-in is shared. ./uninstall removes the two files.
